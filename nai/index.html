System Prompt 프리셋

          
지시사항을 여러 개 저장해 두고 바꿔 쓸 수 있습니다. 대화방 하나는 처음 사용한 지시사항 하나로만 진행되며, 다른 지시사항은 새 대화에서 써야 합니다. 모델은 같은 대화 안에서도 바꿀 수 있습니다.

          

            
            
            
          

          

            
            
            
          

          
아래 내용을 고치고 [저장]을 누르면 선택한 프리셋에 덮어씁니다. 다른 이름으로 남기려면 [새 프리셋으로 저장]을 누르세요(바로 저장됨). 기존 대화는 시작할 때의 내용으로 계속 진행되고, 고친 내용은 새 대화부터 적용됩니다.

        

        

          
System Prompt

          
모든 생성 요청의 첫 system 메시지로 원문 그대로 전달됩니다. 앱은 내용을 요약·교정·삭제하지 않습니다.

          
          

            
            
            
            
            
            
            
          

          
          

          
저장·취소는 아래 버튼으로 합니다. 지시사항 점검은 경고만 표시하며 원문을 고치지 않습니다.

        

      


      
      

        

          
참조 CSV

          
헤더 없는 4열 CSV(tag, category, usage_count, aliases). 파일은 이 브라우저에만 저장되고 로컬에서 검색됩니다. 요청마다 관련 후보만 모델에 전달하며, 파일 전체는 보내지 않습니다. 업로드·교체·제거는 저장 버튼 없이 바로 적용됩니다.

          

            

            

          

          
CSV 파일을 여기에 끌어다 놓거나 업로드를 누르세요

모델 프리셋

          
이 탭의 모델·API·추론·프록시·이미지 설정과 고급 호환 옵션, Planner 설정을 한 묶음으로 저장합니다. 목록에서 고르면 값이 채워지고, 아래 [저장]을 눌러야 적용됩니다. 저장해 둔 프리셋은 사이드바 아래에서 바로 바꿀 수도 있습니다.

          

            
            
            
          

          

            
            
            
            
          

          
프리셋 추가·덮어쓰기·이름 변경·삭제는 바로 저장됩니다. API 키와 프록시 토큰도 프리셋에 함께 저장됩니다(설정 내보내기 때는 기본으로 빠짐).

추론 설정

          
추론(thinking) 모델용 설정입니다. "보내지 않음"이면 요청에 넣지 않습니다. 모델이 지원하지 않는 값을 넣으면 오류가 날 수 있으니 [모델 진단]으로 확인하세요.

          

            

            

            

          

          
Reasoning Effort는 reasoning_effort 필드로 보냅니다(OpenAI o·GPT-5 계열, Gemini OpenAI 호환 등). Thinking Level / Budget은 모델 ID로 공급자를 알 수 있을 때만 보냅니다 (Gemini: extra_body.google.thinking_config, Claude: thinking.budget_tokens). 다른 공급자는 고급 / 진단 › 추가 body JSON을 사용하세요.

        

        

          
프록시

          
브라우저가 CORS 때문에 원본 API를 직접 호출하지 못할 때 사용합니다. 요청 body의 model 값은 위 모델 ID를 그대로 사용합니다.

          
          

          

            

          

          
        

        

          
이미지 입력 (비전)

          
입력창의 클립 버튼·붙여넣기·끌어다 놓기로 이미지를 첨부할 수 있습니다. 비전 모델에서만 동작하며, 보내기 전에 크기를 줄여 JPEG로 바꿉니다(원본은 저장하지 않음). 지원 여부는 [모델 진단]에서 확인할 수 있습니다.
